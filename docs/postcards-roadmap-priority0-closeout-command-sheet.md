# Postcards Roadmap Priority 0 Closeout Command Sheet

Purpose: final condensed command-level checklist for Priority 0 closure execution.

## Command-order checklist
1. Run preflight and confirm environment readiness
2. Capture timing evidence
3. Capture 4-prompt journey evidence
4. Fill gate completion forms
5. Finalize release note with measured values
6. Reconcile evidence index + blocker log + decision record
7. Complete QA signoff
8. Execute go/no-go decision

## Close criteria
- All Priority 0 artifacts updated in same run window
- No status mismatches across evidence files
- QA signoff and decision record present

## Fail-safe
If any command-order step fails, stop closeout, log blocker update, and keep Priority 0 open.
