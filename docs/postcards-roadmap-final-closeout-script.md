# Postcards Roadmap Final Closeout Script

Purpose: one-pass script for the final operator run when browser validation is available.

## Phase 1 — Evidence capture
1. Fill `docs/postcards-live-timing-template.md`
2. Fill `docs/postcards-user-journey-check-log.md`
3. If any prompt fails, stop and log blocker in `docs/postcards-roadmap-blockers-log.md`

## Phase 2 — Evidence normalization
1. Complete one `docs/postcards-roadmap-gate-completion-form.md` section for Gate 2
2. Complete one section for Gate 4
3. Complete one section for Gate 5 after release-note finalization

## Phase 3 — Release-note finalization
1. Update `docs/postcards-architecture-release-note.md` from draft to final
2. Replace all placeholder language with measured values
3. Add final tradeoff statement and residual risks

## Phase 4 — Roadmap close
1. Update `docs/postcards-roadmap-evidence-index.md` statuses
2. Confirm blockers are closed or explicitly carried
3. Add dated closeout line with operator initials

## Exit condition
Priority 0 can be marked closed only if Gate 1-5 each have explicit evidence references and completion form entries.
