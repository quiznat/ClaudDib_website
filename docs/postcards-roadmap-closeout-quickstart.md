# Postcards Priority 0 Closeout Quickstart

Use this when browser runtime is available and you need to execute closure fast.

## 5-minute start
1. Open `postcards-roadmap-closeout-readme.md`
2. Run `postcards-roadmap-final-run-preflight.md`
3. Execute `postcards-roadmap-priority0-closeout-command-sheet.md`

5. Decide using `postcards-roadmap-closeout-go-no-go.md`
