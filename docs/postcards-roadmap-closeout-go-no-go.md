# Postcards Roadmap Closeout Go/No-Go

Purpose: force an explicit go/no-go decision before declaring Priority 0 complete.

## Go criteria (all required)
- [ ] Proofpack complete and cross-consistent
- [ ] Gate forms completed for required gates
- [ ] QA signoff completed
- [ ] Blocker log reconciled (no hidden open blockers)
- [ ] Decision record completed with evidence rationale

## No-Go triggers (any one blocks closure)
- Missing timing/journey evidence
- Placeholder text still present in release note
- Evidence index status mismatches any gate form
- QA signoff absent or missing timestamp/signature

## Decision output
- GO: proceed to final closure statement in evidence index
- NO-GO: keep roadmap open, write specific unblock step + owner + target date
